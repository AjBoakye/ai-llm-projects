# AI System Reconnaissance — Notes

## What is AI Recon?
The process of identifying:
- What model is running  
- How it is deployed  
- What endpoints it exposes  
- What protections exist  
- What weaknesses can be exploited  

## Why It Matters
Recon determines:
- Attack surface  
- Prompt injection vectors  
- Model extraction feasibility  
- RAG vulnerabilities
